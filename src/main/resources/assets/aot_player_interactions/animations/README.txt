Animation categories

paired/ - paired scenes: one JSON file with both roles. Use Refresh to load.
solo/ - reserved for future solo animations; playback is not connected yet.
downed/ - help animations: one JSON with both roles. Help 1 is built in. Confirm your favorite in Help animation to use when helping other players. A player downed in PvP waits in Help 1's first NPC frame; the living player presses V within 10 seconds to start their own favorite. Success restores two hearts. The fallen player cannot cancel; cancellation by the helper resumes the original deadline.
Add files on the server (world owner for single-player/LAN). The owner or an operator can refresh when no interactions are active.
Existing JSON files in this parent folder still load as paired scenes. Clients receive both roles automatically.
