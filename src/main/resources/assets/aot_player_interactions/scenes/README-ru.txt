Категории анимаций

paired/ — парные сцены: один JSON-файл с обеими ролями. Для загрузки нажмите «Обновить».
solo/ — папка для будущих соло-анимаций; запуск пока не подключён.
downed/ — анимации помощи: один JSON с обеими ролями. «Помощь 1» уже встроена. Выберите личное избранное во вкладке «Анимация помощи»: этой анимацией вы будете помогать другим игрокам. Упавший после PvP ждёт в первом кадре NPC из «Помощь 1»; живой игрок нажимает V в течение 10 секунд и запускает своё избранное. Успех поднимает с двумя сердцами. Лежащий не может отменить помощь; отмена помощником возвращает исходный отсчёт.
Файлы добавляет владелец сервера (в одиночной игре/LAN — хозяин мира). Обновление доступно хозяину или оператору, когда нет активных взаимодействий.
Прежние JSON в этой общей папке по-прежнему загружаются как парные сцены. Другие игроки получают обе роли автоматически.
